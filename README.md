# SIGI — Assistência Farmacêutica

Portal estático da Assistência Farmacêutica do Município de Ilhéus, preparado para publicação pelo GitHub Pages.

## Recursos

- atalhos para e-SUS AF, Hórus, formulários e cadastros;
- modo escuro;
- relógio e data;
- controle de temperatura;
- folha mensal para impressão;
- layout responsivo para computador e celular;
- sem login e sem banco de dados.

Desenvolvido por CAUS.
